# Weather Service

 Идея проекта: 
Разработка бэкенд-сервиса для получения актуальных данных о погоде (температура, влажность, скорость ветра, давление), прогноза на различные периоды, а также предоставляющего доступ к историческим наблюдениям. Сервис будет агрегировать данные от внешнего API и предоставлять к ним удобный доступ через REST интерфейс

Погодные метрики:  
Температура (текущая, минимальная/максимальная, как ощущается)   
Влажность    
Скорость и направление ветра  
Атмосферное давление  
Описание погоды (ясно, облачно и т.д.)

Функционал:  
Получение погодных данных по названию города  
Получение погодных данных по геолокации  
Получение прогноза погоды на 7 дней/30 дней/3 месяца  
Получение исторических данных о погодных условиях в конкретную дату  
Получение исторических данных за указанный период

Технологический стек:  
Фреймворк: Spring Boot 3.5.11  
Язык программирования Java 21 (Microsoft OpenJDK)  
Сборщик: Maven 3.8.6  
Кэширование: Redis  
Работа с API: Rest Client  
Управление зависимостями: Spring Boot Starters
