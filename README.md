# Weather Service

Идея проекта: разработка бэкенд-сервиса для получения погодных данных с поддержкой подписок и имитацией платежей. Сервис предоставляет REST API для доступа к текущей погоде, прогнозам, историческим данным, а также систему платных подписок с разными уровнями доступа.

Погодные метрики:
- Температура (текущая, минимальная, максимальная, по ощущениям)
- Влажность воздуха
- Скорость ветра
- Направление ветра
- Атмосферное давление
- Описание погоды (ясно, облачно, дождь, снег, гроза, туман)
- UV-индекс (для прогноза и истории)
- Время восхода и заката (для прогноза и истории)

Функционал:
- текущая погода по городу
- текущая погода по координатам
- прогноз на N дней (до 15 дней)
- исторические данные за период
- исторические данные на конкретную дату
- погода в конкретное время
- почасовой прогноз
- фильтрация прогноза

# Уровни подписок

FREE (бесплатный):
- Лимит запросов в день: 10
- Подписки на погодные уведомления: недоступны
- Доступные функции: текущая погода по городу, текущая погода по координатам

BASIC (500 ₽/месяц):
- Лимит запросов в день: 100
- Подписки на погодные уведомления: 1 подписка
- Доступные функции: все из FREE + прогноз на 15 дней, исторические данные на конкретную дату (до 7 дней назад), исторические данные за период (до 7 дней)

PREMIUM (1000 ₽/месяц):
- Лимит запросов в день: безлимит
- Подписки на погодные уведомления: 5 подписок
- Доступные функции: все из BASIC + погода в конкретное время, почасовой прогноз, фильтрация прогноза, исторические данные на конкретную дату (до 5 лет назад), исторические данные за период (до 8 месяцев)

# Основные возможности
Аутентификация и безопасность:
- Двухфакторная система аутентификации: поддержка как API-ключей, так и cookie-сессий
- После успешного входа сервер устанавливает HttpOnly cookie, которая автоматически подставляется во все последующие запросы
- Все пароли хранятся в захешированном виде с использованием BCrypt
- Авторизованные пользователи могут сменить пароль, указав старый и новый
- При забытом пароле доступно восстановление: на почту приходит 6-значный код, действительный 15 минут
- Разграничение доступа на основе ролей (FREE/BASIC/PREMIUM) через Spring Security

Платежная система:
- Имитация банковских платежей
- При создании платежа генерируется уникальный ID, статус платежа сохраняется в БД
- Подтверждение платежа происходит с вероятностью 80% успеха
- После успешной оплаты автоматически обновляется уровень подписки и генерируется новый API-ключ
- При отклонении платежа пользователь получает email-уведомление и может создать новый платёж

Email-уведомления:
- Регистрация: API-ключ, описание тарифов
- Успешная оплата: новый API-ключ, подтверждение подписки
- Отклонение платежа: уведомление об ошибке
- Погодное предупреждение: жара/мороз/ветер/осадки в подписанном городе
- Истечение подписки (за 3 дня): напоминание о продлении
- Истечение подписки: понижение до FREE, новый API-ключ
- Автопродление: подтверждение продления
- Восстановление пароля: 6-значный код для подтверждения
- Смена пароля: уведомление о смене пароля
- Удаление аккаунта: подтверждение удаления

Кэширование:
- Результаты погодных запросов кэшируются в Redis на 15 минут
- Это снижает нагрузку на внешнее API и ускоряет ответы

Планировщик задач:
- Ежедневная рассылка погодных уведомлений в 08:00
- Проверка просроченных подписок каждый час
- Уведомление о скором истечении подписки за 3 дня

Логирование:
- Все действия пользователей логируются с уровнем INFO и DEBUG
- Ошибки запросов к внешнему API логируются с уровнем ERROR

# REST API Эндпоинты
Аутентификация:
- POST /auth/register?email=&password=&confirmPassword= – регистрация пользователя
- POST /auth/login?email=&password= – вход (устанавливает cookie)
- GET /auth/logout – выход (удаляет cookie)
- GET /auth/check – проверка статуса авторизации

Погодные запросы:
- GET /weather/current?city=&lang= – текущая погода по городу
- GET /weather/current?lat=&lon=&lang= – текущая погода по координатам
- GET /weather/forecast?city=&days=&lang= – прогноз на N дней
- GET /weather/history?city=&start=&end=&lang= – исторические данные за период
- GET /weather/history/date?city=&date=&lang= – исторические данные на конкретную дату
- GET /weather/current/time?city=&datetime=&lang= – погода в конкретное время (PREMIUM)
- GET /weather/forecast/hourly?city=&date=&lang= – почасовой прогноз (PREMIUM)
- GET /weather/forecast/filter?city=&days=&filterCondition=&lang= – фильтрация прогноза (PREMIUM)

Платежи:
- POST /payment/create?level= – создание платежа
- POST /payment/confirm/{paymentId} – подтверждение оплаты
- GET /payment/status/{paymentId} – проверка статуса платежа
- GET /payment/history/page=&size= – история всех платежей пользователя с пагинацией

Управление профилем:
- GET /user/profile – получение профиля пользователя
- GET /user/auto-renewal?enabled= – включение/отключение автопродления
- DELETE /user/account?password= – удаление аккаунта
- POST /user/change-password?oldPassword=&newPassword= – смена пароля
- POST /auth/forgot-password?email= – запрос на восстановление пароля
- POST /auth/reset-password?email=&code=&newPassword= – сброс пароля по коду из письма

Подписки на уведомления (BASIC+):
- GET /subscription/subscribe?city=&notifyHeat=&notifyCold=&notifyWind=&notifyPrecipitation= – подписаться на уведомления о погоде
- GET /subscription/unsubscribe – отписаться от всех уведомлений
- GET /subscription/subscribtions – список активных подписок
- GET /subscription/unsubscribe/{subscriptionId} – отписаться от конкретной подписки

# Конфигурируемые параметры в application.properties
- weather.limits.free – лимит запросов для FREE (по умолчанию 10)
- weather.limits.basic – лимит запросов для BASIC (по умолчанию 100)
- weather.limits.premium – лимит запросов для PREMIUM (по умолчанию -1 = безлимит)
- payment.price.basic – цена подписки BASIC (по умолчанию 500)
- payment.price.premium – цена подписки PREMIUM (по умолчанию 1000)
- payment.success-probability – вероятность успеха оплаты (по умолчанию 0.8)
- payment.expire-minutes – время жизни платежа в минутах (по умолчанию 15)
- password.reset.expire-minutes – время жизни кода восстановления (по умолчанию 15)
- weather.alert.heat-threshold – порог жары для уведомлений (по умолчанию 30)
- weather.alert.cold-threshold – порог мороза для уведомлений (по умолчанию -20)
- weather.alert.wind-threshold – порог ветра для уведомлений (по умолчанию 15)
- redis.cache.ttl-minutes – время жизни кэша в минутах (по умолчанию 15)
